# 🤖 AI Quiz Platform

An AI-powered quiz platform that generates intelligent quizzes, evaluates user responses, and provides instant feedback. The application leverages modern web technologies and AI to create an engaging and personalized learning experience.

---

## 🚀 Features

- User Registration & Login
- AI-powered Quiz Generation
- Multiple Quiz Categories
- Real-time Quiz Evaluation
- Instant Score Calculation
- Personalized AI Feedback
- Quiz History
- Responsive User Interface
- Secure Authentication
- MongoDB Database Integration

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Quiz-Platform.git
```

```bash
cd AI-Quiz-Platform
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
OPENAI_API_KEY=your_openai_api_key
JWT_SECRET=your_secret_key
```
